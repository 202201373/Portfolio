### Pneumonia Detection with Optimized CNN and Explainable AI
`Python` `TensorFlow` `Keras` `LIME`

- Developed a CNN for pneumonia detection from chest X-ray images. Particle Swarm Optimization tuned the learning rate, dropout, filter configuration and optimizer.
- Used Hill Climbing to tune the PSO parameters, giving a nested optimization approach to CNN hyperparameter search.
- Applied LIME to explain predictions and compared Grey Wolf Optimizer, Harmony Search, Firefly Algorithm and Bat Algorithm for LIME parameter optimization.
- Compared explanation quality with Intersection over Union (IoU) and stability scores to pick the best optimizer.
